What is Bayesian Shrinkage? It prevents artists/albums with very few rated songs from dominating the rankings with unreliable averages.

The adjusted score blends an artist's raw average with the global mean, weighted by sample size:

adjusted = (songs × avg + C × globalMean) / (songs + C)
  • Few songs rated → score pulled toward global mean (not enough data to trust)
  • Many songs rated → score stays close to real average (reliable)

C = 0: no shrinkage, pure averages  ·  C = 5: moderate (default)  ·  C = 20: heavy, everyone converges toward the mean
